# Rajesh K — Personal Portfolio

Personal portfolio website built to showcase my skills, certifications, and project as a Computer Science student. Built with plain HTML, CSS, and JavaScript — no frameworks, fully responsive.

**Live site:** _add your deployed link here once hosted (e.g. via Netlify or Vercel)_

## About

I am a Computer Science student building practical skills across the full stack. This site presents my completed certifications, current areas of study, and the project I have built to date.

## Features

- Responsive layout — works on mobile, tablet, and desktop
- Sticky navigation with mobile hamburger menu
- Scroll-triggered section reveal animations
- Skills grouped by category (Frontend, Backend, Database, Tools)
- Certifications list
- Featured project section
- Direct contact links (email, phone, GitHub, LinkedIn)

## Built With

- HTML5
- CSS3 — custom properties, Grid & Flexbox, no framework
- Vanilla JavaScript — IntersectionObserver, DOM APIs
- [Google Fonts](https://fonts.google.com/): Space Grotesk, Inter, IBM Plex Mono
